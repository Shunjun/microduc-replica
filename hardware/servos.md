# 舵机

## 本机约定

使用飞特 1910，软件配置按 **HD-1910-C001**；用户确认舵机 ID 与原版 XL330 一致。完整铭牌后缀、固件版本仍待照片或读回记录。

| 项目 | 选择 / 说明 |
| --- | --- |
| 总数 | 15 颗；RL 控制其中 14 个运动关节，嘴部独立 |
| 供电 | 标称 7.4 V，用户确认 |
| 总线 | 单线半双工 TTL，当前驱动 1,000,000 baud、8N1 |
| P 寄存器 | **21 / 0x15，按用户明确指示处理** |
| 普通运动 P | 180 |
| 站立增益 | 原项目按比例降低；随包配置比例 0.8，对应 P=144 |
| 摔倒/低增益 P | 40 |
| EEPROM 写锁 | 用户要求不额外操作写锁；驱动不主动切换地址 55 |

P 是位置环比例系数，不是“力矩百分比”，不能把飞特 180 与 XL330 200 直接当作同一物理刚度。持续/掉电保存行为由当前固件和锁设置决定，具体实现见[飞特驱动设计](../microduck/docs/design/feetech-hardware.md)。

厂家 BAM 采集代码使用地址 50，但用户最终确定本机按地址 21。地址 50 仅作来源差异记录，不据此改本机寄存器；也没有证据在这里断言它必然是本机的“临时 P”。

## 已查到的厂家规格

以下性能点来自[厂家型号详细页](https://www.feetechrc.com/510257)，条件为 **4.8 V**；不能冒充本机 7.4 V 性能。

| 参数 | 厂家标注 |
| --- | --- |
| 堵转扭矩 | 9 kgf·cm，约 0.883 N·m @4.8 V |
| 额定负载 | 2.2 kgf·cm，约 0.216 N·m @4.8 V |
| 空载速度 | 0.137 s/60° @4.8 V |
| 堵转电流 / 额定电流 | 1.2 A / 0.5 A @4.8 V |
| 重量 / 尺寸 | 21±2 g / 34×20×23 mm |
| 减速比 / 齿轮虚位 | 320:1 / ≤0.5° |
| 编码器 | 4096 计数/圈 |

堵转是短时边界，不能作为持续输出能力；无需为开始训练去做危险的堵转试验。规格来源、厂家 7.4 V 动力学参考和实测项的完整区分见[RL 飞特配置](../microduck_rl/src/mjlab_microduck/robot/feetech1910/README.md)。

## 工具与验证状态

- 用户已测试可用的[飞特网页调试器](https://juxi-technology.github.io/FT-ServoController-web/)。这证明该工具能调试用户舵机，不等于当前 Rust 驱动已完成整机验收。
- 运行端分为 `duck-control/src/xl330/` 与 `duck-control/src/feetech1910/`；公共控制逻辑见[驱动关系](../microduck/docs/design/hardware-drivers.md)。
- 零位、方向、机械限位与单位换算仍以实物标定为准，不能复制 XL330 的零位填充飞特文件。
