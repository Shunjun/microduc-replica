# 主控与供电

## 用户已确认的选型

| 部件 | 本机选择 |
| --- | --- |
| 主控 | 香橙派 Orange Pi Zero 3W，1 GB |
| SoC | A733 |
| 扩展板 | 原 Microduck 项目同款 HAT |
| 关节执行器 | 飞特 1910，15 颗，见[舵机记录](servos.md) |
| 舵机电源 | 7.4 V，2026-11-26 用户确认 |

**Orange Pi Zero 3W 与原项目 Radxa Zero 3W 是不同主板。** 名字相近不能用来判断 GPIO 编号、串口/I²C 控制器编号或设备树是否一致。

用户要求保持原版 HAT 的物理接线，因此优先适配香橙派对应引脚和 Linux 设备节点，而不是任意换到另一个 UART。

## 供电记录

- 用户讨论过主控使用充电宝供电；没有留下供电能力、线损和长时间稳定性的实测结果。
- 舵机母线标称 7.4 V，不是香橙派 USB 的供电电压；两者不可混为一项训练参数。
- 当前没有记录舵机实际电源型号、限流值、HAT 电源走线或带载压降曲线。
- 用户确认“7.4 V 供电”，并不等于已经确认电源一定是 2S 电池；不按电池类型自行补充事实。
